# Áudios Demonstrativos — Feito de Nós

Para testar a reprodução de áudio real nesta fase, adicione nesta pasta os arquivos:

1. `mensagem-pais.mp3` — Mensagem principal gravada pelos pais.
2. `mensagem-avos.mp3` — Mensagem gravada pelos avós.
3. `mensagem-padrinhos.mp3` — Mensagem gravada pelos padrinhos.

Enquanto os arquivos MP3 não forem adicionados, o player exibe automaticamente um estado amigável informando "O áudio será adicionado em breve", sem quebrar a interface nem disparar erros na tela.
