# Imagens e Fotografias do Presente — Feito de Nós

Para testar com fotografias reais da família, adicione nesta pasta:

1. `hero-matheus.jpg` — Foto principal de capa do Matheus Akira (formato vertical/retrato 4:5 ou similar).
2. `month-01.jpg` até `month-12.jpg` — Fotos de cada um dos 12 meses do primeiro ano (formato quadrado 1:1).
3. `avatar-pais.jpg`, `avatar-avos.jpg`, `avatar-padrinhos.jpg` — Fotos dos autores das mensagens.
4. `gallery-01.jpg` até `gallery-12.jpg` — Fotos do álbum de memórias.

Enquanto as fotos reais não forem adicionadas, os componentes exibem placeholders editoriais afetivos com a paleta oficial da marca.
