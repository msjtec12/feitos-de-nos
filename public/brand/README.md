# Arquivos da Marca — Feito de Nós

Coloque nesta pasta os seguintes arquivos oficiais:

1. `logo-feito-de-nos.png` — Logo principal horizontal ou vertical da marca.
2. `simbolo-feito-de-nos.png` — Símbolo do laço/nó da marca.

Se os arquivos não estiverem presentes, a aplicação utiliza automaticamente os componentes vetoriais SVG e tipográficos nativos configurados com as fontes DM Serif Display e a paleta oficial.
